photoflowy 개인정보 처리방침

시행일: 2026년 7월 4일 · 최종 수정일: 2026년 7월 4일

본 개인정보 처리방침은 Clipflowy(이하 “개발자” 또는 “회사”)가 제공하는 모바일 애플리케이션 photoflowy(이하 “앱”)를 이용하는 사용자의 개인정보를 어떻게 수집·이용·보관·보호하는지를 설명합니다. photoflowy는 사용자가 선택한 사진, 포토북, 매직 포토북, 전자 액자 세션을 기기 안에서 관리하는 로컬 우선(local-first) 사진/포토북 앱입니다.

1. 핵심 요약

  • 사용자가 여는 사진 및 포토북 파일(CBZ, CB7, ZIP, PBZ, PB7, 이미지, Markdown 노트, .pfslide 등)과 진행률·책장·레이아웃·캡션·노트·검색 색인·리마인더·설정은 기본적으로 사용자 기기 내부에 저장되며, 회사 서버로 업로드되지 않습니다.
  • 회사는 사용자의 원본 사진, 포토북 내용, 검색 색인, AI 대화 내용을 광고 타게팅 목적으로 열람하거나 수집하지 않습니다.
  • 광고(Google AdMob), 원격 설정(Firebase Remote Config), 앱 내 구매, 선택적 AI/TTS/Chromecast 기능을 제공하기 위해 일부 기기 정보, 광고 식별자, 구매 정보 또는 사용자가 명시적으로 보낸 콘텐츠가 제3자 서비스에서 처리될 수 있습니다.
  • 외부 AI, Cloud TTS, 외부 디스플레이, Chromecast, 사진/카메라 접근은 사용자의 명시적 동작 또는 운영체제 권한 허용 후에만 사용됩니다.

2. 수집하는 정보 및 이용 목적

2.3 자동으로 처리될 수 있는 정보

앱 및 제3자 SDK는 서비스 제공·보안·오류 진단을 위해 IP 주소, 기기 모델, 운영체제 버전, 앱 버전, 언어 설정 등 일반적인 기술 정보를 일시적으로 처리할 수 있습니다. 회사는 원본 사진, 포토북 내용, 로컬 검색 색인을 광고 타게팅에 사용하지 않습니다.

4. 광고 및 추적(App Tracking Transparency)

앱은 Google AdMob을 통해 광고를 표시할 수 있습니다. iOS에서는 추적을 위해 사용자의 명시적 동의(App Tracking Transparency)를 요청할 수 있으며, 동의하지 않으면 맞춤형(개인화) 광고 대신 비개인화 광고가 제공될 수 있습니다. 회사는 사용자의 사진, 포토북, 검색 기록, AI 대화, 리마인더 내용을 광고 개인화에 직접 제공하지 않습니다. 광고 개인화는 다음에서 관리할 수 있습니다.

  • iOS: 설정 → 개인정보 보호 및 보안 → 추적
  • Android: 설정 → Google → 광고
  • Google 광고 설정: https://adssettings.google.com

5. 개인정보의 보관 및 파기

로컬에 저장된 앱 데이터는 사용자가 앱을 삭제하거나 앱 내 데이터 삭제 기능을 사용하면 제거됩니다. 앱 목록에서 항목을 삭제해도 사용자가 직접 선택한 원본 파일은 보통 삭제되지 않으며, 앱 내부에 복사된 파일은 사용자가 삭제할 수 있습니다. 운영체제의 기기 백업 기능이 켜져 있으면 일부 로컬 데이터가 Apple 또는 Google의 백업 정책에 따라 백업될 수 있습니다. 제3자 서비스가 처리하는 데이터의 보관 기간은 해당 서비스의 정책을 따릅니다.

9. 보안

회사는 합리적인 기술적·관리적 보호조치를 적용합니다. API 키, 인증 토큰, 앱 잠금 정보 등 민감한 로컬 데이터는 가능한 경우 운영체제의 보안 저장소(Keychain/Keystore)를 사용하여 보관합니다. 다만 인터넷을 통한 전송이나 전자적 저장이 100% 안전함을 보장할 수는 없습니다.

10. 방침의 변경
